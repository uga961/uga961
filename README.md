## About Me

I'm Ugandhar, an Electronics and Communication Engineering graduate with interests spanning data science, intelligent software systems, and engineering research.

I enjoy understanding how things work and applying that knowledge to build useful solutions. My projects range from AI-assisted engineering drawing analysis and competitive intelligence to data analysis, desktop applications, and transistor-level circuit design.

- **Data science:** Data analysis, visualization, statistical reasoning, and machine learning.
- **Artificial intelligence:** LLM integrations, multi-agent workflows, document intelligence, and AI-assisted automation.
- **Software development:** Python applications, web technologies, APIs, and desktop tools.
- **Engineering:** Electronics, CMOS circuit design, VLSI, embedded systems, and hardware-software integration.
- **Research and analytics:** Technical research, supplier analysis, product benchmarking, and structured decision support.
- **Technical writing:** Documenting projects, tutorials, experiments, and experiences on my personal blog.

My approach is straightforward: understand the problem, explore the data, build a solution, validate the results, and document what I learn.
